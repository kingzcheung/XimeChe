# libximecore xime-plugin 引擎迁移：mlua → quickjs-rusty 0.14（对齐 xime 3.0 JS 契约）

## 目标

`xime-plugin` crate 从 mlua 整体切换到 `quickjs-rusty = "0.14.0"`，插件侧契约完整对齐 Android 3.0（`globalThis.plugin` 分组命名空间 + host 3.0 API + manifest.json），使 Android 的 JS 插件可以直接装到 Linux 运行。**Rust 端 API 面（方法名/签名/类型）保持不变**，XimeChe 与 xime-setup-lib 的生产代码零改动。

已确认的关键前提：
- quickjs-rusty 0.14.0 的 Context 是 `!Send`——已验证 XimeChe 中 PluginRuntime 从不跨线程（DBus 只传命令、PluginHost 归 wayland 循环线程、clipboard_sync 桥在专用线程自建自用），xime-setup-lib 是一操作一实例。无需 unsafe Send 或 actor 改造。
- 本地构建经 `.cargo/config.toml` 的 `[patch]` 指向 `/home/kkch/vscode/libximecore`，改完自动生效。

## 一、libximecore 侧（/home/kkch/vscode/libximecore）

### 1. 依赖
- 根 `Cargo.toml` `[workspace.dependencies]` 新增 `quickjs-rusty = { version = "0.14.0", default-features = false, features = ["serde"] }`（裁掉 chrono/bigint）。
- `crates/xime-plugin/Cargo.toml`：移除 mlua，加 `quickjs-rusty.workspace = true`。

### 2. runtime.rs 整体重写（核心工作）

**保留不变**：全部导出类型（EmojiItem、BackupUploadResult、RemoteBackupEntry、SettingField、CandidateTransform*、EmojiLayout、RuntimeError/RuntimeResult、uuid_string）、`PluginRuntime::load(plugin_dir, entry, config_file)` 签名、全部契约方法名、失败降级语义（缺失/报错一律 None/默认值/原样返回，不上抛）。

**新引擎结构**：
- `PluginRuntime { context: Context, plugin_id: String }`；插件导出对象 = `globalThis.plugin`。
- 契约调用统一走 Android 同款 eval 表达式模式（同时解决 this 绑定、方法缺失降级、Promise settle）：`(globalThis.plugin && globalThis.plugin.emoji && typeof globalThis.plugin.emoji.listCategories === 'function') ? globalThis.plugin.emoji.listCategories(...) : undefined`。
- 参数经 native `__ximeSetArg`（serde to_js）注入 `globalThis.__ximeArg`；返回值 `from_js`/serde 反序列化为目标类型。二进制用 Uint8Array 桥（构造/读取走属性访问，执行期验证 serde 对 typed array 的支持后可简化）。
- 插件返回 Promise（如 `clipboardSync.push: Promise<boolean>`）时用 eval `resolve=true` + `execute_pending_job` 阻塞落定；host API 全部同步阻塞实现（JS `await` 普通值合法，Android 插件的 await 写法无感）。
- 超时：interrupt handler（函数指针 + `Box<AtomicI64>` deadline opaque，Drop 回收），常量对齐 Android：transform 15ms / 事件回调 5s / 业务 180s；超时后 runtime 中毒，后续调用走降级路径。
- 内存上限：Context 构造时 64MB。
- 沙箱 bootstrap JS（参照 Android JsScriptRuntime.kt）：屏蔽 `eval`/`Function`（require 用预先捕获的原始 Function 编译模块）、console 转发 host.log/logError、TextEncoder/TextDecoder/atob/btoa（经 `__ximeHost` 原生 utf8/base64 助手）、XimeError、definePlugin。
- require（CommonJS-lite）：仅插件目录内相对 `.js`、≤2MB、带缓存；路径解析在 Rust 侧实现（`__ximeHost.resolveModule/readModule`，拒绝 `..`/绝对路径穿越）。

**host 对象（对齐 Android 3.0）**：`sdkVersion = "3.0.0"`；log/logError/uuid；config.get/set/remove/keys/getJson（后端仍是 YAML config 文件）；resource.path/list（同步）；bin.int32be/uint32be；zlib.gzip/gunzip；crypto.sha256/hmacSha256/hmacSha1/hex/base64/utcTime/epochSeconds；http.request(method,url,headers,body,timeoutMillis) → `{status,headers,body:Uint8Array,text}`（ureq 阻塞，默认 20s）；quickSend.list()→[]、clipboard.get()→null（占位，同现状）；capabilities=[]、has()→false（能力门禁现状即未实现）。不注入：ws/asr/http.stream（后续阶段）。移除 Lua 时代的 host.json（JS 有原生 JSON）、host.clipboard.getText/setText、host.quickSend.send。

**Rust 方法 → JS 分组命名空间映射**：

| Rust 方法（签名不变，除注明） | JS 调用 |
|---|---|
| call_on_load / call_on_unload | plugin.onLoad() / plugin.onUnload()（可 async） |
| get_categories() | plugin.emoji.listCategories() → Vec\<String\> |
| get_emojis(cat,search,top_k) | plugin.emoji.query({category,keyword,topK}) → EmojiItem（text 空丢弃） |
| get_category_layout(category) | 返回 None（Android 契约布局在 manifest；方法保留向后兼容） |
| clipboard_push/pull | plugin.clipboardSync.push/pull |
| test_connection() | plugin.clipboardSync.test() 优先，回落 plugin.backup.test()（None/空串=成功） |
| push_backup/pull_backup/list_backups/delete_backup | plugin.backup.push({name,archive})/pull(id)/list()/remove(id) |
| get_settings_schema() | plugin.settings.schema() → XimeUiNode[] 最佳努力映射 SettingField：text/input/textarea/number/metric→"text"、secret→"secret"、button/action→"button"，select/switch/section/divider/multi_select 跳过并记日志，≤64 节点 |
| get_panel_state / on_panel_input / on_panel_action / on_panel_item_click | plugin.panel.state / onInput / onAction / onItemClick |
| create_asr_backend / feed_audio_data / stop_asr | plugin.speech.isConfigured?/feed/stop（best-effort，无消费方） |
| transform_candidates（**签名升级**，当前无消费方可自由改） | 增加 input_text/preedit/ascii_mode 参数，调 plugin.transform.candidates({inputText,preedit,asciiMode,candidates})，15ms 超时，解析 {engineIndex?}|{text,comment?} |
| send_event(type,data) | slot 命名 snake→onPascal：plugin.events.onTextCommitted(payload)，5s fire-and-forget |
| ~~call_fn\<T: FromLuaMulti\>~~（Lua 专属，移除） | 新增 `call_plugin_fn(path, args: &[serde_json::Value]) -> Option<serde_json::Value>`（支持 "emoji.query" 点路径，测试辅助） |

### 3. manifest.rs
- 新增 `parse_json`（serde_json 严格解析；Android 的注释/尾逗号宽松度不做，注明差异）。
- `from_dir`/`load_manifest`/install 校验：manifest.json 优先，回落 manifest.yaml（兼容存量安装）。
- `default_entry()` → `"main.js"`；更新相关测试。

### 4. manager.rs / lib.rs / capabilities.rs
- manager.rs：仅测试 fixture 改为 manifest.json + main.js（+ libs/util.js、resources/）。
- lib.rs 头注释措辞 lua→js；capabilities.rs 零改动。

### 5. 测试移植
runtime.rs 的 12 个内联测试全部改为 JS fixture：4 个契约插件（emoji/clipboard_sync/backup/tool）重写为 `globalThis.plugin` IIFE 形态；沙箱断言改为 eval 屏蔽 + require 穿越拒绝；config/JSON roundtrip、libs require 缓存、crypto RFC 4231 向量、utcTime SigV4 形状全部保留。
